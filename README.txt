دفتر التحضير الذكي – أكاديمية EVA للتدريب
===========================================

موقع ثابت (HTML) لا يحتاج خادمًا ولا قاعدة بيانات ولا مفاتيح API.
كل شيء يعمل داخل متصفح المستخدم، ونصوص التحضير لا تُرسل إلى أي مكان.

الملفات:
  index.html             الصفحة كاملة (الواجهة + محرّك التوزيع والرسم + PDF)
  template.jpg           قالب دفتر التحضير الرسمي (A4، 2120×3000)
  icon-192.png / 512     أيقونة التطبيق عند الإضافة إلى الشاشة الرئيسية
  manifest.webmanifest   يجعل الموقع قابلًا للتثبيت كتطبيق
  sw.js                  يجعل الموقع يعمل دون إنترنت بعد أول زيارة
  og.jpg                 الصورة التي تظهر عند مشاركة الرابط على واتساب وفيسبوك

النشر (اختر طريقة واحدة):
  1) Netlify: أنشئ حسابًا مجانيًا، ثم اسحب هذا المجلد كاملًا إلى صفحة «Deploy manually / Drop».
  2) Cloudflare Pages: أنشئ مشروعًا جديدًا بخيار «Upload assets» وارفع المجلد.
  3) GitHub Pages: ارفع الملفات إلى مستودع عام، وفعّل Pages من الإعدادات.
  ثم يمكنك ربط اسم نطاق خاص (مثل daftar.eva-academy.com) من إعدادات المنصة.

ملاحظة: افتح الموقع من رابطه بعد النشر. فتح index.html مباشرة من الحاسوب يعمل،
لكن ميزة العمل دون إنترنت لا تعمل إلا من رابط https.
